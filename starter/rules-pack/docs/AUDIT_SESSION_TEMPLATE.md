# Audit Session Template

**Status: STUB — needs to be designed in a dedicated session.**

This template is planned for a future session. The goal is a structured format for running each of the 5 audit gates so every audit is consistent, thorough, and produces a logged result.

---

## Planned audit types to cover:

| Audit | When | Question |
|---|---|---|
| 1 — Buildability | Before first code | Is the design spec'd well enough to build? |
| 2 — Feel | After first playable / working build | Does it work in practice? What's wrong? |
| 3 — Scope | Before full production | What does production actually require? |
| 4 — Coherence | Mid-production | Do systems still fit together as scope grows? |
| 5 — Polish | Pre-release | Is this ready to ship? |

## What the template should include per audit type:
- Pre-audit checklist (what must be true before running)
- Questions to answer during the session
- Pass / conditional pass / fail criteria
- Output format (what to log in DECISIONS.md)
- Model recommendation (all audits: Opus)
