## Section A — EA Launch (skip if no Early Access)

### Build
- [ ] EA build exported and tested on all target platforms
- [ ] EA build passes all applicable audits (Performance, Privacy, Legal)
- [ ] No critical bugs open
- [ ] Debug overlays / dev tools removed or disabled

### Store Page
- [ ] Title and short description finalized — includes "Early Access" framing
- [ ] Long description written — clearly states what IS and ISN'T in EA
- [ ] EA FAQ section filled (what's the current state? what's the plan? how long in EA?)
- [ ] Screenshots: EA-appropriate (no placeholder art without disclosure)
- [ ] Capsule art / icon finalized
- [ ] Tags and categories set
- [ ] Age rating submitted

### Platform Setup
- [ ] Developer account active and in good standing
- [ ] Payment / payout setup complete
- [ ] Store page submitted for review (allow 2–5 days for Steam/Apple)

### Legal / Safety
- [ ] Privacy policy live and linked
- [ ] No unlicensed assets in build
- [ ] API keys / secrets not in repo or build

### Marketing
- [ ] EA launch announcement drafted (Steam Hub / itch.io blog / social)
- [ ] Wishlist / follow link ready for announcement
- [ ] [Optional] Press kit ready
