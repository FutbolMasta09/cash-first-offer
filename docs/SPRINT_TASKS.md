## How to Use

1. Work tasks in order — later tasks depend on earlier ones
2. Check off each task when committed + passing lint/test
3. Do not skip ahead — if blocked, document the blocker in `docs/DECISIONS.md`
4. Add new tasks discovered during build at the bottom of the relevant section
